# Изменения сайта «Спасение»

## 2026-10-07 — SEO/GEO и данные для поисковых систем

- Серверный срок кэширования обновляемых `robots.txt`, `sitemap.xml`, `llms.txt`, `llms-full.txt` и ленты статей главной страницы сокращён до 10 минут. GoDaddy/CDN переопределяет его для `robots.txt` и `.js`; поэтому генератор ленты теперь меняет её URL по хешу содержимого при каждой публикации. Для `robots.txt` долгий срок на стороне CDN пока остаётся ограничением.
- В структурированные данные 44 опубликованных русских и английских материалов добавлены фактические `datePublished` и `dateModified`. Видимых дат на страницах статей и в каталогах статей не добавлено.
- Для всех 48 опубликованных URL в `sitemap.xml` добавлен `<lastmod>`. Скрипт `scripts/sync-publication-metadata.mjs` воспроизводит эти данные при следующих публикациях, не добавляя в карту сайта будущие статьи.
- Прошедший анонс Праздника Жатвы в `llms.txt` явно помечен как архивный на двух языках.
- Журнал наблюдаемых цитирований LLM не заполнен искусственными данными: отсутствие подтверждённых наблюдений не приравнивается к нулевой видимости.
